# 📊 Excel Report Generator

This is a **Flask web application** that allows users to **upload Excel files** and automatically generate:
- 🎓 Participation Report  
- 📈 Performance Report  

It processes Excel data using **Pandas** and **OpenPyXL**, and outputs formatted reports ready for download.

---

## 🌟 Features
- Simple one-page web interface  
- Upload Excel files directly from the browser  
- Automatically formats and generates reports  
- Download processed Excel files instantly  
- Clean, blue-themed UI
